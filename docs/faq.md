# FAQ

## Is emotion inference reliable?

No. It is probabilistic and may be wrong, biased, or contextually inappropriate.

## Can this evaluate employees?

No. Do not use it for employment, health, disciplinary, or access decisions.

## Does the Node package run the application?

The documented entry point is Python `main.py`; `package.json` is legacy metadata and currently references an absent `index.js`.

## What data should be used?

Synthetic or properly de-identified data with informed consent.
